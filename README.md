# linknest

LinkNest landing page project, now scaffolded as a Vite + React + TypeScript app for direct Git-based deployment to Vercel.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
